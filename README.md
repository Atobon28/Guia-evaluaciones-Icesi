# Evaluación + IA — Universidad Icesi

Base completa en React + Vite + TypeScript para una guía web interactiva.

## Correr el proyecto

```bash
npm install
npm run dev
```

## Manual de marca aplicado

- Azul Icesi: `#5454E9`
- Blanco como base principal.
- Verde Icesi como acento de progreso/confirmación.
- Tipografía principal: Plus Jakarta Sans.
- Cards, navegación lateral, stepper, semáforo, selector AIAS, plantillas y checklist.
